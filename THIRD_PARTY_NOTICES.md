# Sources and third-party materials

This private collaboration repository contains project-specific analysis code, frozen protocols and result summaries. No new open-source licence has been selected for the original project code. Private access does not relicense third-party materials or establish permission for public redistribution.

- **Wong / antibioticsai:** source repository `felixjwong/antibioticsai`, pinned commit `83403d483def9aa6a90df850b3d0454b3030cf47`. Upstream repository materials carry an MIT licence; the retrieved text is preserved at `third_party/wong-antibioticsai-LICENSE.txt` and within the original data snapshot. Journal supplementary materials remain subject to their own applicable terms. See `reports/source_manifest.json` for exact URLs and hashes.
- **Harvard screen:** PubChem BioAssay AID 1259311. Preserve depositor attribution, source SIDs, assay metadata and file provenance. This project does not claim ownership of the measurements or resolve missing stock/final concentration information.
- **CO-ADD:** source assay tables and derivative audit/split files preserve their original provenance. Public redistribution terms were not resolved by the original project; review the provider terms before any public release.
- **SyntheMol source data:** retrieved source snapshots and manifests are retained in the private artifact bundle. Their original metadata and applicable upstream terms remain in force. This repository is not the original SyntheMol implementation.
- **Software dependencies:** Chemprop, RDKit, descriptastorus, PyTorch, Lightning, scikit-learn and other packages retain their respective licences. Dependencies are installed separately rather than vendored into this repository.

For scientific attribution, cite the Wong paper (DOI `10.1038/s41586-023-06887-8`), the underlying assay/data providers and the methods used, as well as this repository's exact commit and artifact release. A model ranking is not a new experimental discovery.
